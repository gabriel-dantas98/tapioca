Três skills, uma massa só

O conteúdo de hoje é PT-BR — é o primeiro recheio, não a tese. Cada skill ganha agent companion quando a tarefa pede multi-pass. Tudo namespaceado em /tapioca:.

01 /tapioca:humanizer-br

humanizer-br

Tira o cheiro de IA de texto em português e devolve voz humana de verdade. Catálogo de 25+ padrões.

  • Linguagem promocional, gerúndio empilhado, regra dos três
  • Roda 100% no Claude/CLI, sem API key externa
  • Agent companion faz multi-pass com autoavaliação
02 /tapioca:usabilidade-br

usabilidade-br

Audita um app web contra as 10 heurísticas de Nielsen e devolve um report HTML self-contained.

  • Score por heurística + evidência visual embutida
  • Snippet de código com file:line quando localiza
  • Fix prompt copiável por violação
03 /tapioca:multi-gen

multi-gen

Dispara vários CLIs de IA em paralelo a partir de um briefing e monta um comparativo lado a lado.

  • codex + cursor-agent em paralelo, timeout portável
  • Valida cada SVG e extrai do log sujo
  • Preview com painel claro, escuro e tira de favicons

Instalação

Mesma massa, três cozinhas. Escolha a sua.

Adicione o marketplace e instale o plugin. As skills viram atalhos /tapioca:* na hora.

# 1. registra o marketplace /plugin marketplace add gabriel-dantas98/tapioca # 2. instala o plugin /plugin install tapioca@tapioca

Em dev, sem marketplace: claude --plugin-dir /caminho/para/tapioca

O repo carrega o manifesto do Cursor em .cursor-plugin/ com a mesma skills/ e agents/ por baixo.

# adiciona o marketplace tapioca Cursor → Settings → Plugins → Add marketplace gabriel-dantas98/tapioca # depois instale o plugin "tapioca" pela lista
⚠ caminho diferente

O Claude Desktop não consome plugins nem marketplaces — isso é coisa do Claude Code. O que viaja pro Desktop é Skill avulsa. Das três, só a humanizer-br roda lá (as outras dependem de CLIs e do Chrome MCP).

# empacote a skill como pasta/zip zip -r humanizer-br.zip skills/humanizer-br/ # suba em Claude Desktop: # Settings → Capabilities → Skills → Upload

Agents e o namespace /tapioca:* não existem no Desktop — é a skill pura.
